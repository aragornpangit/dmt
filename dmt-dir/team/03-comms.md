# 通信与工具选择

## 通信

- 直接子代理通过平台原生返回通道只向派发者回报。
- **回执三步**：发送文本 → 显式提交回车 → 复核输入已被接受，缺一步视为未送达，不凭「写入终端」判断送达。herdr 走 `pane send-text` + `pane send-keys <pane> enter` + `pane read` 核验；Orca 走 `orca terminal send --terminal <id> --text '<msg>' --enter --wait-submit 15`（`terminal send` 默认**不追加回车**，必须显式 `--enter`）。用哪个通道由 [`02-runtime.md`](02-runtime.md) 第 1 步的运行平台判定结果决定，不按 harness 猜。
- 跨进程角色可使用项目现有消息机制；启用 DMT 收件箱时按 [`../ops/comms.md`](../ops/comms.md) 操作。
- 回报包含目标、结论、产物、证据和未决项；阻塞与能力缺失也沿同一方向回报。

### 长回执与交接件

终端回滚窗口有限，长回执会被截断；换 harness 或换会话等于换进程，上下文只能靠自述延续。约定：

- 回执超过一屏（约 40 行）时落盘为 `<role>-reply-<YYYYMMDD-HHMM>.md`，终端只回「路径 + 三行结论」。
- 交接（换 harness、换会话、上下文接近上限）时写交接件；新会话**只读交接件开工**，不靠回忆复述。模板：

```markdown
# <角色> 交接 — <主题>（<YYYY-MM-DD HH:MM>）

## 目标与状态
- 目标：<一句话>
- 当前状态：<已完成 / 进行中 / 阻塞>
- 上一动作与结果：<命令或动作> ⇒ <rc / 结论>

## 产物与证据（必须可复现）
| 产物 | 路径（绝对或仓内） | 身份/校验 |
|---|---|---|
| … | … | <sha256 / commit / 文件行号> |

## 未决项（接手人必须知道）
- <待裁 / 待跑 / 待补>

## 口径限制（不得外推）
- <跨包不横比 / 单写者 / 样本 n / 已作废轮次>

## 下一步（按序）
1. …
```

- 交接件写**证据路径**而非结论摘要：接手人凭路径复核，不凭转述。
- `/tmp` 下的件会丢：关键结论回写仓内证据桶，交接件只留指针。

## 工具与技能

- 根据任务选择当前环境可用且适合的工具，不强制特定供应商、技能包或版本；项目启用第三方技能适配器时按 [`../ops/optional-skills.md`](../ops/optional-skills.md) 的点名表执行。
- 工具不可用时说明影响，并采用可验证的替代方法；需要用户授权的能力不能自行放开。
- 加载技能后先按 [`02-runtime.md`](02-runtime.md) 第 1 步探测两轴环境；平台特定的调用方式见 [`../harness/README.md`](../harness/README.md)，只在实际使用时读取。
- 多写者共享文件时可启用 [`../ops/file-claim.md`](../ops/file-claim.md) 的占用协调；单写者工作区无需额外仪式。
