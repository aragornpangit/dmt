# dmt-director

技能名 `dmt-director`（运行 id `director`）的角色技能目录：含 `SKILL.md`、`team.md` 与 `scripts/`（十八个确定性动作脚本：落盘机检 `check-dmt-doc-paths.sh`、文件占用 `file-claim.sh`、初始化 `init-project.sh`、建团队 `setup-team.sh`、建 helper `spawn-helper.sh`（`<director|devm|anam>`，本体的纯分身、每角色至多一个，建 helper tab / `{角色}-helper` pane 并代启动 harness，幂等，支持 `--dry-run` / `--no-start`）、关 helper `close-helper.sh`（`<director|devm|anam>`，支持 `--force` / `--dry-run`，方向过滤安检后回收 helper pane，helper tab 保留复用）、消息 `send-msg.sh` / `msg-take.sh` / `msg-done.sh`、派发账本与 hooks `dispatch-ledger.sh` / `self-work-guard.sh` / `parallel-guard.sh` / `probe-cap.sh` / `fanout.sh` / `install-hooks.sh`、推送 `publish.sh`、安装 `install-skills.sh`、一键拉起团队 `launch.sh`（install-skills → init-project → install-hooks → setup-team，幂等可分段跳过））。

**仓库说明与安装（根 README.md）**：见 [README.md](../README.md)（项目总说明、安装、机检、维护与团队契约索引）。
