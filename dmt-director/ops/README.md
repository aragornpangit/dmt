# dmt 操作手册（按任务拆分）

`OPS.md` 是兼容入口；按任务只读需要的一份：

| 任务 | 文件 |
|---|---|
| pane / tab / 启动 / 权限 / helper 生命周期 | [`runtime.md`](runtime.md) |
| 收件箱 / 门铃 / 认领 / 收口 | [`comms.md`](comms.md) |
| 编辑前文件占用 | [`file-claim.md`](file-claim.md) |
| helper 建立、分流、回报、回收 | [`helper.md`](helper.md) |
| 权限事故实证与逃生舱 | [`permission-notes.md`](permission-notes.md) |

安装后路径为 `docs/ops/<name>.md`。规范冲突仍以 `team.md` 为准。
